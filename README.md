# Бортовой компьютер Dualtron Achilleus

Минималистичная монохромная приборка для **Dualtron Achilleus • 60V 16S • 2× Flipsky 75100 Pro V2**. На экране — скорость, напряжение/заряд батареи, мощность и ток, температуры, Field Weakening, пробег и состояние контроллеров. Веб-интерфейс не отправляет конфигурационные записи в VESC; кнопка подключения только устанавливает BLE-соединение.

## Открыть приборку

**GitHub Pages:** https://sanlaran.github.io/vesc/

## Подключение

1. Включите самокат и BLE на телефоне.
2. Откройте страницу по HTTPS и нажмите **«ПОДКЛЮЧИТЬ BLE»**.
3. В системном окне выберите BLE-устройство контроллера VESC/Flipsky.

На iPhone стандартные Safari и Chrome не предоставляют Web Bluetooth. Откройте HTTPS-ссылку в браузере с Web Bluetooth для iOS, например Bluefy. На Android используйте Chrome. Разрешите доступ к Bluetooth, когда браузер запросит его.

Без установленного BLE-соединения приборка показывает **симуляцию**, отмеченную на экране. По одному только факту открытия страницы нельзя считать данные реальными. Двойное касание спидометра переключает замеры разгона и GPS-скорость; GPS-калибровка диаметра меняет только настройку отображения в браузере, не настройки VESC.

## Запуск локально

```bash
npm ci
npm run dev
```

## GitHub Pages и ключ Яндекс Карт

GitHub Actions собирает сайт и публикует `dist` на Pages. Ключ Яндекс Карт задан как клиентский ключ в `src/config.ts`; при необходимости его можно переопределить через `VITE_YANDEX_MAPS_API_KEY` во время сборки.

Ключ JavaScript API неизбежно доступен браузеру. Ограничьте разрешённые HTTP referrer-домены в кабинете Яндекс Cloud, включая `https://sanlaran.github.io/*`. Не используйте клиентский ключ с неограниченными правами.
